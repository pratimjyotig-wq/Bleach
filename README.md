# ⚔️ BLEACH Character Archive

Welcome to the **BLEACH Character Archive**!

This is a fan-made website dedicated to the anime and manga
**BLEACH**, featuring character information, Zanpakutō, Shikai,
Bankai and abilities.

## 📖 Features

- ⚔️ BLEACH character information
- 🗡️ Zanpakutō details
- 🔥 Shikai information
- 💀 Bankai information
- 🔎 Character search
- 📚 Character database

## 👤 Characters

Currently included:

- Ichigo Kurosaki
- Byakuya Kuchiki
- Rukia Kuchiki
- Renji Abarai

More characters will be added.

## 🛠️ Technologies

This website is built using:

- HTML
- CSS
- JavaScript
